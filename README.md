# Assignment for İstinye University DGD202 Game Engines 1

## Animation Practice & Cinemachine Practice

### Melih ULUKOZ

This Unity project contains two small practices for DGD202 Game Engines 1.

## Contents

- **Animation Practice:** A controllable 3D character using a Mixamo model and animations.
- **Cinemachine Practice:** A small cinematic sequence using 4 Cinemachine cameras and a custom blend.

## Controls

- **WASD:** Move
- **Left Shift:** Run
- **Space:** Jump
